# DefaultStackr testpagina

Kleine publieke Node.js-pagina om een eerste DefaultStackr-deploy te controleren.

- Installatie: `npm ci`
- Build: `npm run build`
- Start: `npm run start`
- Health path: `/healthz`
- URL: wordt door het platform aangemaakt als `<slug>.defaultstackr.cloud`

De app gebruikt geen sleutels, betaalgegevens of database.
